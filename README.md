# Temperature and humidity monitor

A microclimate monitoring system built on an Arduino microcontroller with BLE (Bluetooth Low Energy) connectivity and a dedicated Android application.

## Used technologies

* Kotlin - Android application development
* C++   - Arduino firmware & sensor communication logic

## Requirements

* Android Studio Panda 2| 2025.3.2
* Arduino IDE (v. 2.3.6)

## Hardware Requirements

* Microcontroller - Arduino UNO R4 WiFi
* Any telephone with android
* Sensor - DHT11 Temperature & Humidity Sensor
    * [this library](https://botland.com.pl/index.php?controller=attachment&id_attachment=1210) must be installed in Arduino IDE to handle the sensor
